A QUICK FIELD GUIDE / 03

A few details about the files and how this generator handles your input.


What are the generated files for?
The JSON file contains reference metadata, and the Lua file contains SteamTools commands. These are generated templates with simulated identifiers; they do not contain actual Steam depot manifests.


Where do I find a Steam App ID?
Find your game on SteamDB or in the Steam store. The number in a store URL after /app/ is the Steam App ID.


What happens to the ID I enter?
Your browser uses the ID to request public game details from Steam and generate the files locally. This site does not store your input.


Can I edit the files after downloading?
Yes. Open the JSON or Lua template in a text editor and adjust it to your needs.
