A quick field guide / 03

          
Good to know.

          
A few details about the files and how this generator handles your input.

        

        

          

            What are the generated files for?
            
The manifest JSON contains app metadata and generated identifiers. The Lua script provides the corresponding app and manifest commands for your workflow.

          

          

            Where do I find a Steam App ID?
            
Search for a game on SteamDB and copy the numeric App ID from its page.

          

          

            What happens to the ID I enter?
            
The ID is used to request public game details from Steam. File generation and downloads happen locally in your browser.

          

          

            Can I edit the files after downloading?
            
Yes. Both downloads are plain text files that you can open and edit with your preferred editor.
