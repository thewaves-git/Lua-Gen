    A few details about the files and how this generator handles your input.

    What are the generated files for?

    Lua scripts are fetched from the steamtoolsapp/ManifestHub repository on GitHub. Individual depot manifests are listed from the same game branch. The public SteamTools endpoint provides available key.vdf and ZIP downloads.

    Where do I find a Steam App ID?

    Find your game on SteamDB or in the Steam store. The number in a store URL after /app/ is the Steam App ID.

    What happens to the ID I enter?

    Your App ID or game name is sent through this site’s backend to the public SteamTools API to search for games and retrieve download links. Lua files and manifest listings are fetched from GitHub. This app does not save your searches.

    Can I edit the files after downloading?

    Lua and key.vdf are text files. Follow the installation instructions returned by SteamTools, and keep a backup before editing.
